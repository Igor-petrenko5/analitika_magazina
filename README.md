# Аналитика действий пользователей интернет-магазина

Учебный проект загружает CSV в SQLite, проверяет схему, считает популярность товаров, выручку и конверсии, строит интерактивный HTML-отчёт и экспортирует показатели в Excel. Запуск по расписанию выполняет Apache Airflow.

## Состав проекта

- `data/DZ_user_actions.csv` — исходные данные (локальный файл, в публичный репозиторий не загружен).
- `src/pipeline.py` — единый воспроизводимый ETL и аналитический пайплайн.
- `sql/metrics.sql` — запросы для ключевых показателей.
- `dags/analytics_dag.py` — DAG Airflow с ежедневным запуском.
- `docker-compose.yml` — локальный Airflow для учебного запуска.
- `output/` — сюда создаются база, Excel и HTML-отчёт.

## Схема и трактовка показателей

В файле шесть столбцов: `user_id`, `product_id`, `action`, `category`, `price`, `timestamp`. Идентификаторы — целые числа, `price` — десятичная сумма, `timestamp` — дата-время. Действия: `view`, `add_to_cart`, `purchase`. Выручка считается только по событиям `purchase` как сумма `price`.

Конверсии рассчитаны по уникальным парам «пользователь–товар» и учитывают порядок времени: просмотр → последующее добавление в корзину → последующая покупка.

## Быстрый запуск локально

Нужен Python 3.10+ и пакеты из `requirements.txt`.

```powershell
cd analytics_shop
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python src/pipeline.py --input data/DZ_user_actions.csv --output output
```

После запуска появятся `output/analytics.db`, `output/метрики_аналитики.xlsx` и `output/отчёт.html`. Откройте HTML в браузере. Графики Plotly загружаются с CDN, поэтому для отображения графиков нужен доступ к интернету.

### Подготовка исходного CSV

Чтобы повторить расчёт, скачайте исходный файл по [ссылке из задания](https://drive.google.com/file/d/1y6OivwORg-eihHJQD6ttuz_O1B6HgxV0/view?usp=sharing) и сохраните его как `data/DZ_user_actions.csv`. Сам CSV и построчная SQLite-база исключены из публичного репозитория, поскольку содержат пользовательские события. После добавления файла запустите команду пайплайна выше.

## Запуск Airflow через Docker Compose

Нужны Docker Desktop и Docker Compose. Из корня проекта:

```powershell
docker compose up airflow-init
docker compose up -d
```

Откройте `http://localhost:18080` (логин и пароль: `airflow`), включите DAG `analitika_magazina` и запустите вручную кнопкой Trigger DAG. DAG также запускается ежедневно. Результаты сохраняются в `output/` на компьютере. Для остановки: `docker compose down`.

## Результаты проверки исходных данных

В наборе 10 000 событий, 50 пользователей и 100 товаров; пропусков в ожидаемых полях нет. Действия распределены почти равномерно: 3 333 просмотра, 3 307 добавлений в корзину и 3 360 покупок. Общая сумма покупок — 1 680 380,11. Самая высокая выручка у категории «Дом» — 368 973,62. По последовательной воронке 2 426 пар товаров просмотрено, для 691 из них затем добавили товар в корзину (28,48%), а 153 дошли до покупки (22,14% от добавлений; 6,31% от просмотров).

Для проверки схемы и метрик см. `sql/metrics.sql`. Пайплайн повторно пересоздаёт таблицу событий в SQLite из CSV, так что база всегда соответствует последней загрузке.
