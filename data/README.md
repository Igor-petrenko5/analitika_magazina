# Исходные данные

Исходный CSV не хранится в публичном репозитории, так как содержит события на уровне пользователей.

Скачайте `DZ_user_actions.csv` по [ссылке из задания](https://drive.google.com/file/d/1y6OivwORg-eihHJQD6ttuz_O1B6HgxV0/view?usp=sharing) и положите этот файл в папку `data/`. Затем запустите пайплайн командой из корневого README.
